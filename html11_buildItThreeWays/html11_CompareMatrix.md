# html11f — Test & Compare

## Step 1: The same usability test, three times

Run this checklist against ALL THREE builds (hand-coded, AI, builder). Same standards, no favoritism — you're a professional evaluator now, not a proud parent.

For each build record pass / partial / fail + one sentence:

- [ ] Every nav link works; no dead ends
- [ ] Readable on a phone-width window
- [ ] Every image has meaningful alt text
- [ ] Heading hierarchy is logical (one h1, no skips)
- [ ] The form is labeled and usable
- [ ] The table reads correctly
- [ ] Load feel: anything noticeably heavy?
- [ ] Consistent look across pages
- [ ] W3C validator on the hand-coded and AI builds (builders won't give you clean access to markup — note THAT too)
