# html10 Extension Task: The Audit-and-Fix Pass

**For fast finishers. Extra credit — no points, no rubric. Finish the regular html10 tasks first.**

## The task

Your site is live on GitHub Pages. Now audit it like a professional would — with web-based tools (no dev tools needed):

1. Run your live URL through **PageSpeed Insights** — https://pagespeed.web.dev (this is Google Lighthouse running in the cloud). Record your Performance and Accessibility scores.
2. Run it through **WAVE** — https://wave.webaim.org. Record the errors and alerts it finds.
3. Pick **three real findings** across the two tools and fix them (compress that image, add that alt text, fix that contrast ratio, add that meta description).
4. Re-run both tools.

## What to commit

`html10_ExtensionAudit_lastname.md` containing: before scores/findings, what you fixed and how, after scores/findings. Plus the actual fixes, pushed.

## Done when

- [ ] Before and after results recorded for both tools
- [ ] Three findings genuinely fixed (not suppressed)
- [ ] The report explains each fix in a sentence or two
- [ ] Pushed to GitHub
