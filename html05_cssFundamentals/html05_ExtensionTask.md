# html05 Extension Task: Three Themes, One Page

**For fast finishers. Extra credit — no points, no rubric. Finish the regular html05 tasks first.**

## The idea

The entire point of CSS is that content and presentation are separate. Prove it: one HTML file, three completely different looks, and the *only* thing that changes is which stylesheet is linked.

## The task

1. Pick one of your existing pages (About Me works well). Save a copy as `html05_ExtensionThemes_lastname.html`. You may not edit its HTML again after step 2.
2. Make sure its content is fully styled through an external stylesheet link — zero inline styles, zero `<style>` blocks.
3. Create three stylesheets: `theme_light.css`, `theme_dark.css`, and `theme_wild.css`. Each must set, at minimum: page background, text color, font family, link colors (including `:hover`), and heading treatment. The three themes should look *obviously* different — not just a background swap.
4. Test each theme by changing only the `href` in the single `<link>` tag.

## What to commit

- `html05_ExtensionThemes_lastname.html` (linked to whichever theme you like best)
- `theme_light.css`, `theme_dark.css`, `theme_wild.css`

## Done when

- [ ] The HTML contains no inline styles and no style block
- [ ] Swapping one `href` completely retheme the page
- [ ] All three themes set backgrounds, text, fonts, links (+hover), and headings
- [ ] All four files pushed to GitHub
