# html12 — Web Design Exam Prep

Everything for reviewing before the state Web Design exam (WebXam). Use the files in the order below.

## 1. Colors, SEO, and Protocols review

Folder: [`colorsSeoProtocols/`](colorsSeoProtocols/)

| File | What it is |
|---|---|
| `html12_ColorsSeoProtocols_StudyGuide.md` | The study guide for these three topics. **Video links are at the top.** |
| `slides/` | The slides your teacher shows in class (PDF) |
| `html12a_Colors_lastname.md` | Task: web colors (RGB and hex) |
| `html12b_SEO_lastname.md` | Task: Search Engine Optimization |
| `html12c_Protocols_lastname.md` | Task: internet protocols |

Download each task, rename it with your last name, answer the questions, and push it to an `html12` folder in your own `htmlCssJavaScript` repo.

## 2. Full exam review

| File | What it is |
|---|---|
| `html12_FullExam_StudyGuide.md` | Study guide for the **whole** exam: layout, forms, SEO, accessibility, protocols, troubleshooting, business and ethics |
| `html12_Troubleshooting_lastname.md` | Task: troubleshooting, test cases, and project planning scenarios |
| `html12_PracticeExam.md` | 40-question timed practice exam |
