# html04 Extension Task: The Real-World Table & Captioned Figures

**For fast finishers. Extra credit — no points, no rubric. Finish the regular html04 tasks first.**

## The task

**Part 1 — A table that earns its complexity.** Build `html04_ExtensionSchedule_lastname.html` containing a realistic weekly schedule table (a school day, a team practice week, a TV lineup — your pick) that requires:

- A `<caption>` describing the table
- `<thead>`, `<tbody>`, and `th` cells with the `scope` attribute
- At least one `colspan` **and** one `rowspan` used meaningfully (a lunch block spanning columns, an event spanning two time slots)

**Part 2 — Figures done right.** On the same page, add two images wrapped in `<figure>` with a `<figcaption>` each. The caption should add information (who/what/where), not repeat the alt text — alt describes the image for someone who can't see it; the caption comments on it for everyone.

## What to commit

- `html04_ExtensionSchedule_lastname.html` (plus your image files)

## Done when

- [ ] Table has caption, thead/tbody, and scoped `th` cells
- [ ] At least one meaningful colspan and one rowspan
- [ ] Two figures with captions that *add* to (not repeat) the alt text
- [ ] Every image still has proper alt text
- [ ] Pushed to GitHub
