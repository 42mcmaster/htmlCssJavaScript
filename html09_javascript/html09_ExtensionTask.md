# html09 Extension Task: The Feature Menu

**For fast finishers. Extra credit — no points, no rubric. Finish the regular html09 tasks first.**

Every one of these is the same four moves you already know — select, listen, toggle, let CSS finish. Pick any (each one counts separately). Add them to your real site.

## The menu

1. **FAQ accordion** — questions that expand/collapse on click. (The old html10 walkthrough's "Putting It All Together" section in this folder's teacher materials shows the pattern.)
2. **Scroll-to-top button** — appears after you scroll down, click returns to top. Hint: listen for the `scroll` event on `window`, toggle a class that shows/hides the button.
3. **Image lightbox** — click a thumbnail, a large version appears over the page; click anywhere to dismiss.
4. **Tabs** — three buttons, three content panels, one visible at a time. (Hint: this one toggles classes on *two* things per click.)

## What to commit

Your updated site with each feature working, plus one sentence per feature in the commit message saying what you added.

## Done when

- [ ] Each chosen feature works by mouse AND keyboard
- [ ] No feature broke dark mode or the hamburger (test both after each addition)
- [ ] Pushed to GitHub
